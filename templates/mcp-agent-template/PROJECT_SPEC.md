# Project Spec

## Goal

Provide a reusable MCP agent baseline with safe tool discovery, typed tool-call
results, fake MCP client tests, and a minimal FastAPI UI.

## In Scope

- MCP client boundary.
- Tool allowlisting.
- Structured tool results.
- Fake MCP tests.

## Out Of Scope

- Running arbitrary local commands.
- Unrestricted external tool execution.
- RAG corpus management.
