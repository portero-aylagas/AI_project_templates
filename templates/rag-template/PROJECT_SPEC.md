# Project Spec

## Goal

Provide a reusable RAG baseline with ingestion, chunking, embedding boundary,
retrieval, grounded structured answers, citations, and evaluation fixtures.

## In Scope

- Deterministic document loading.
- Chunking and retrieval boundaries.
- Fake embeddings.
- Citation-bearing structured answers.

## Out Of Scope

- Production vector database provisioning.
- Web crawling.
- Unreviewed document trust.
