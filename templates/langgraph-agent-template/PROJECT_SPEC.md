# Project Spec

## Goal

Provide a reusable LangGraph-style workflow baseline with typed state,
deterministic routing, prompt files, fake model calls, and a minimal FastAPI UI.

## In Scope

- State schema.
- Node functions.
- Conditional routing.
- Graph smoke tests.

## Out Of Scope

- Free-form LangChain tool agents.
- MCP tool discovery.
- Vector-store RAG.
