# Project Spec

## Goal

Provide a reusable human-in-the-loop baseline with AI draft generation, review
queue, approve/edit/reject decisions, persisted state, audit log, and minimal
FastAPI review UI.

## In Scope

- Structured drafts.
- Human decisions.
- Persisted run state.
- Audit records.

## Out Of Scope

- Fully autonomous high-risk actions.
- Complex user authentication.
- Multi-tenant production deployment.
