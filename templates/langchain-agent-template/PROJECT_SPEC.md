# Project Spec

## Goal

Provide a reusable LangChain tool-agent baseline with structured outputs,
debuggable tool calls, fake tools, and a minimal FastAPI UI.

## In Scope

- Typed tool contracts.
- Agent orchestration boundary.
- Fake-client and fake-tool tests.
- Structured final response.

## Out Of Scope

- LangGraph state machines.
- MCP tool discovery.
- RAG corpus management.
